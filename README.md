# DEMI Algorithm for Home Diagnosis of COVID-19

## Project Overview

This project develops a home-based COVID-19 diagnostic artificial intelligence system using the COVIDCARE Phase II dataset and a Direct Effects Multiplicative Inference (DEMI)-informed framework.

The objective is to estimate the probability of PCR-confirmed COVID-19 using information that could reasonably be available before clinical evaluation, including demographic characteristics, vaccination status, symptoms and exposures, and at-home testing information.

## Dataset

This project uses the COVIDCARE Phase II Survey dataset (MIT, 2021).

- 822 participants
- 472 variables
- DEMI knowledge base containing 70,983 pairwise concept records
- Survey data dictionary containing descriptions of the 472 variables

Three source files are used:

1. COVIDCARE Phase II patient-level dataset
2. COVIDCARE DEMI knowledge base
3. COVIDCARE survey dictionary

Participants without a documented PCR test result were excluded from the predictive analysis, resulting in a final analytic cohort of 559 participants. Of these, 58 were PCR positive and 501 were PCR negative.

Course materials were obtained from:
http://openonlinecourses.com/causalanalysis/CovidSymptoms.html

## Methods

The analysis was conducted in Jupyter Notebook using Python 3.

The project includes:

- Selection and preprocessing of home-available predictors
- Five-tier temporal organization of diagnostic information
- DEMI pairwise odds-ratio and log-odds-ratio analysis
- Logistic regression
- LASSO logistic regression
- XGBoost classification
- ROC curve and AUC analysis
- Evaluation of accuracy, sensitivity, specificity, precision, and F1 score
- Conceptual directed acyclic graph (DAG)
- Example patient-level COVID-19 probability prediction

### Five-Tier Diagnostic Framework

- **Tier 0:** Demographic and baseline information
- **Tier 1:** Vaccination information
- **Tier 2:** Symptoms and exposures
- **Tier 3:** At-home testing
- **Tier 4:** PCR-confirmed COVID-19 outcome

## DEMI Analysis

The supplied DEMI knowledge base was used to evaluate pairwise associations between clinical concepts and PCR-confirmed COVID-19. Odds ratios and log odds ratios were calculated from knowledge-base occurrence counts.

The strongest pairwise associations included chest pain, a positive at-home test, loss of taste, shortness of breath, appetite change or loss, and loss of smell.

These estimates represent pairwise total associations and should not be interpreted as fully adjusted direct causal effects.

## Predictive Models

Three predictive models were evaluated using a stratified 75% training and 25% testing split:

| Model | AUC | Accuracy | Sensitivity | Specificity | F1 |
|---|---:|---:|---:|---:|---:|
| XGBoost | 0.941 | 0.943 | 0.733 | 0.968 | 0.733 |
| LASSO | 0.938 | 0.921 | 0.733 | 0.944 | 0.667 |
| Logistic Regression | 0.938 | 0.950 | 0.867 | 0.960 | 0.788 |

XGBoost achieved the highest AUC, while logistic regression demonstrated the highest sensitivity, accuracy, and F1 score at the 0.50 classification threshold.

## Example Patient Prediction

The highest-AUC model was applied to a hypothetical patient reporting:

- Fever
- Muscle aches
- Cough
- Loss of taste

The model estimated an **8.7% probability of PCR-positive COVID-19** for this example patient.

This probability was generated by the highest-performing machine-learning model within the DEMI-informed framework and does not represent a complete recursive DEMI direct-effect probability calculation.
